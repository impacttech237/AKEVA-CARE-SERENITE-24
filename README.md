# Akeva Care Sérénité 24

Site web professionnel — accompagnement à domicile et à l'hôpital à Yaoundé et Douala.

## Stack

- Next.js 14 (App Router)
- React 18
- CSS custom (design system crème / terracotta, motion type Medora)

## Démarrer

```bash
npm install
npm run dev
```

Ouvre [http://localhost:3000](http://localhost:3000).

## Avant mise en ligne

Mettre à jour dans `lib/site.js` :

- `phoneDisplay` / `phoneTel` / `whatsapp`
- `email`
- `url`

Les demandes de devis s'ouvrent dans WhatsApp avec un message prérempli.

## Pages

Accueil, services (9 pages), familles, fonctionnement, formules, devis, FAQ, diaspora, villes (Yaoundé, Douala), à propos, conseils, contact, mentions, confidentialité.
